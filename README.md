# GPA-Calculator
GPA calculator for both weighted and unweighted GPA

This is an XLSX file for calculating GPA. You can import it into Excel or Google Sheets to open and use it. 

Enter your numerical grades for each semester to see your automatically calculated GPA. It will calculate weighted and unweighted GPAs, as well as GPAs for each semester/grade level!

The title 8th/9th/10th represent each grade level, and you have two columns for each semester.
